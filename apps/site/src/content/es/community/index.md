# Community

Solidiom is built in the open on GitHub. Join us.

## Get Involved

- [Contributing Guide](/community/contributing/) — how to contribute code, docs, and accessibility evidence
- [GitHub Repository](https://github.com/openCenter-cloud/solidiom) — source code, issues, and discussions
- [Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) — our community standards

## Reporting Issues

Found a bug or have a feature request? Open an issue on GitHub with:

- A clear description of the problem or request
- Steps to reproduce (for bugs)
- Expected vs. actual behavior
- Browser and OS information (if relevant)

## Security

Report security vulnerabilities privately via GitHub Security Advisories. Do not open public issues for security concerns.
