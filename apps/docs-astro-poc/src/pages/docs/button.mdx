## Overview
The Button primitive provides accessible, composable button components.
## Usage
### Basic example
```tsx
import { Root as Button } from "@solidiom/button"
;<Button onClick={() => console.log("clicked")}>Click me</Button>
```

<ButtonDemo client:visible />
## API Reference
Import `Root` from `@solidiom/button` to render a button. The demo passes its label as children and handles `onClick` to update its click count.
