# COMP-003..008 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete COMP-005 Alert, COMP-006 Dialog, COMP-007 Select, COMP-008 Dropdown Menu, COMP-003 Field, and COMP-004 Card component vertical slices.

**Architecture:** Two tiers. Tier 1 (COMP-005..008): add EN+ES examples to existing recipe wrappers and docs, rebuild registry to promote documentation status to "complete". Tier 2 (COMP-003..004): full greenfield — recipe definition, wrappers for 3 profiles, EN/ES docs+examples, emitter runs, registry rebuild.

**Tech Stack:** SolidJS, TypeScript, pnpm workspace, Tailwind/UnoCSS/CSS profiles

## Global Constraints

- Recipe definitions go in `tools/recipe-contract-definitions.ts`
- Token references use `{ token: "name" }` — must exist in `tools/recipe-contract-tokens.ts`
- `font-sans` has null tailwind spelling — use `{ token: "font-sans", fallback: "system-ui, -apple-system, sans-serif" }` for font-family
- New scopes MUST be registered in `SCOPE_STATES` in `packages/runtime/src/dom/semantic-vocabulary.ts`
- Recipe wrappers follow pattern: CSS profile re-exports primitive namespace, Tailwind uses twMerge, UnoCSS uses classnames
- All flags are `data-*` attributes, not `data-state` — use `flags` not `states` in recipe definition for them
- Examples frontmatter: `contentSchemaVersion: 1`, `product: <Name>`, `productLayer: component`, `section: examples`, `exampleId: <scope>-component-basic`, `runnable: true`
- ES examples add `translationSourceHash` (sha256 of EN file) and `translationStatus: draft`
- After each task: rebuild registry (`pnpm run registry:build`), run gate (`pnpm run gate:phase1`), commit
- Phase 1 gate must pass 254/254 after each component

}

export function StyledField(props: StyledFieldProps) {
  const className = () =>
    twMerge(
      `${BASE_CLASSES} ${DISABLED_CLASSES}`,
      props.class,
    )

  return <Field.Root {...props} class={className()} />
}
