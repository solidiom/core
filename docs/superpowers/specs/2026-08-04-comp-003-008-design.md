## Design

### Tier 1 — Examples-only (COMP-005..008)

Each needs:
1. EN examples directory with `basic.md`
2. ES examples directory with `basic.md` (translated, with `translationSourceHash` and `translationStatus: draft`)
3. Registry rebuild to promote `documentation.status` from `"review"` to `"complete"`
4. Task tracker update (mark `[x]`, advance Components DoD counter)
5. Gate verification + commit

### Tier 2 — Greenfield (COMP-003..004)

Each needs the full COMP-001/002 pipeline:
1. Recipe definition in `tools/recipe-contract-definitions.ts` (add to `REFERENCE_DEFINITIONS`)
2. Register scope in `SCOPE_STATES` in `packages/runtime/src/dom/semantic-vocabulary.ts`
3. Recipe wrappers for css, tailwind, unocss profiles
4. Source mirrors for source installs
5. EN component doc + examples
6. ES component doc + examples (translated)
7. Package.json updates: add primitive dependency, add `./styles/<name>.css` export
8. Run all 3 emitters (`recipe:emit:css`, `recipe:emit:tailwind`, `recipe:emit:unocss`)
9. Run `source:emit`
10. Build all 3 recipe packages
11. Registry rebuild
12. Gate verification + commit

### Execution Order

COMP-005 → COMP-006 → COMP-007 → COMP-008 → COMP-003 → COMP-004

Quick wins first (tier 1), then greenfield (tier 2). Each commits independently.

### DoD Per Component

- `registry/components/<name>.json` has `documentation.status: "complete"`
- Recipe wrappers in all 3 profiles exist and build
- Reference definition in `REFERENCE_DEFINITIONS`
- EN/ES docs exist
- At least one example exists
- Component catalog gate: components meeting M4 bar matches tracker declared count
- Phase 1 gate: 254/254 passing
- Task tracker: COMP-<N> marked `[x]`, Components DoD counter incremented

### Example Content Pattern

Based on COMP-001 Button:
- EN `basic.md`: Frontmatter with `contentSchemaVersion: 1`, `product`, `productLayer: component`, `exampleId`, `source`, `runnable: true`. Body with prose + 2-4 code sections showing usage.
- ES `basic.md`: Same structure, translated prose, `translationSourceHash` from sha256 of EN file, `translationStatus: draft`.

### Known Token Gotchas

- `font-sans` has `null` tailwind spelling — use `{ token: "font-sans", fallback: "system-ui, -apple-system, sans-serif" }` for any font-family declarations
- Input recipe had `states` for what are actually `flags` — verify each primitive's state vs flag emissions before writing recipe definitions
- Greenfield scopes MUST be registered in `SCOPE_STATES` before the contract validator will pass
