# Release 0.5.0

Minor release 0.5.0. This is a coordinated workspace-wide minor bump: every published `@solidiom/*` package moves from `0.4.0` to `0.5.0` in lockstep. The release grows the catalog from 52 to **86 primitives**, extends the executable accessibility scan to cover the full catalog, expands the recipe contract to 60 canonical token identities across 32 recipe-covered primitives, and reconciles the documentation set with the current implementation.

## Versioning

All published packages are versioned together at `0.5.0`. Internal-only packages (`@solidiom/bench`, `@solidiom/eslint-plugin-solidiom`, `@solidiom/adapter-kit`, `@solidiom/release-tools`, `@solidiom/test-doubles`, and the probe harnesses) are excluded from release and remain unpublished.

## Highlights

- **Catalog grows to 86 primitives.** 34 new primitives ship alongside the 52 GA (`stable`) primitives, including app-shell, sidebar, grid, stack, table, typography, chart, code-block, the chat family (composer, layout, message, message-metadata, system-message, tool-calls), and form controls (date-range-input, file-input, input-group, number-input, time-input, tokenizer, multi-selector, segmented-control). The 52 original primitives remain `stable`; the 34 additions are marked `experimental`.
- **Accessibility scan extended to all 86 primitives.** The executable axe-core browser scan (`tests/a11y/primitives-axe-scan.browser.test.tsx`) now enumerates and passes all 86 primitives with zero violations, up from the 52 GA surface.
- **Recipe contract widened to 60 canonical token identities.** The cross-profile recipe contract (`tools/recipe-contract-tokens.ts`) grows from 48 to 60 token identities, with recipe coverage expanding from 13 to 32 primitives across the CSS, Tailwind, and UnoCSS profiles.
- **Documentation reconciled with the codebase.** A repository-wide documentation audit corrected catalog counts, workflow/deploy topology, security headers, Solid 2 version references, and dead links, and added a grouped table of contents.

## Accessibility: tiered coverage

Accessibility conformance in 0.5.0 is tiered by primitive status:

- **52 GA (`stable`) primitives** remain the conformance promise: each carries a per-primitive published evidence record (`packages/*/docs/accessibility/evidence.json`) and is enforced by the A11Y-004 coverage gate. WCAG 2.2 AA / APG compliance for these primitives is unchanged.
- **34 `experimental` primitives** are now covered by the executable axe scan (86/86 passing, 0 violations) but are intentionally **not** GA-gated and do not yet publish per-primitive evidence.

In short: **86 scanned = 52 GA-conformant + 34 experimental (scanned, not yet GA-promised).**

Extending the scan surfaced and fixed four real component accessibility/compatibility defects in the newer primitives:

- **`@solidiom/sidebar`** — `Panel` rendered `<aside role="navigation">`, an invalid ARIA-in-HTML combination (`aria-allowed-role`); it now renders `<nav>` with the accessible name preserved.
- **`@solidiom/tokenizer`** — `Token` carried `role="option"` under a `role="group"` root (invalid required-parent) with a nested interactive remove button; the invalid role was removed.
- **`@solidiom/stack`** — `Root` rendered a dynamic string tag that Solid 2 rejects (`createComponent` expected a component, got a string), so `Stack.Root` could not render; it now renders a literal element.
- **`@solidiom/multi-selector`** — the `role="combobox"` trigger had no accessible name; the trigger now accepts an `aria-label` passthrough as ARIA requires for a combobox.

## Notable changes

### Catalog

- **Primitives:** 52 → 86 (34 new `experimental` primitives; 52 remain `stable`).
- **Components:** 30 → 32 recipe wrappers.
- **Templates:** 29 → 31 application starters.
- **Blocks:** 36 page-level composables (unchanged).
- **Adapters:** 6 framework-neutral algorithm engines.
- **Theme presets:** 4 (Ocean, Forest, Slate, Aurora), all WCAG AA in light and dark modes.

### Recipe contract

- Canonical token identities: 48 → 60 (`tools/recipe-contract-tokens.ts`).
- Recipe coverage: 13 → 32 primitives across `@solidiom/recipes-css`, `@solidiom/recipes-tailwind`, and `@solidiom/recipes-unocss`.
- `data-state` known scopes: 35 → 53 (42 stateful, 11 stateless) in `SCOPE_STATES`.

### Documentation

- Added `docs/TOC.md` — a grouped index of the full documentation set — and reconciled `docs/README.md` with the current tree.
- Corrected catalog counts, the Cloudflare Pages project name, security headers (`X-Frame-Options`, CSP), release-workflow triggers, and Solid 2 RC version references across architecture, guides, operations, QA, and plans docs; fixed dead links.
- Added additive coverage notes to the WCAG audit and axe-scan reports clarifying the 86-scanned / 52-GA tiering. Dated evidence snapshots and the historical Beta-1 evidence index are left unchanged.
- Reconciled the recipe and theme contract docs with current code (token and scope counts).

## Solid 2 compatibility

`solid-js` and `@solidjs/web` continue to target the `2.0.0-rc` line; the Solid 2 support window and the `@solidiom/astrojs-solid-next` peer range are unchanged from 0.4.0.
