# Solidiom Beta 1 — August 7, 2026

**Task:** BETA-003
**Status:** Published

Solidiom Beta 1 marks the completion of the full catalog: all primitives, components, blocks, templates, and themes meet the M4 Definition of Done. The platform is functional, tested across browsers, and ready for public evaluation.

## What's Included

### Primitives — 52

Headless, accessible building blocks with full accessibility evidence. Every primitive ships with:

- Keyboard interaction contracts verified by browser tests
- ARIA semantics enforced at compile time via TypeScript generics
- axe-core scan results committed as evidence artifacts
- Bilingual documentation (en/es)

### Components — 30

Styled recipe wrappers that compose primitives with layout, semantic styling slots, and variant support. Available across three styling recipes:

- **CSS** — Native CSS custom properties and BEM-style class names
- **Tailwind** — Tailwind CSS utility composition
- **UnoCSS** — UnoCSS atomic class mapping

### Blocks — 36

Page-level composables with loading, empty, error, and restricted states. Covering authentication, settings, billing, observability, and common enterprise workflows.

### Templates — 29

Full application starters with routing, state management, and theming. Across Balanced and Enterprise portfolios, covering SaaS, internal tools, and commerce patterns.

### Themes — 4 presets

- **Ocean** — Cool blue palette
- **Forest** — Earthy green tones
- **Slate** — Neutral gray scale
- **Aurora** — Vibrant gradient accents

All presets meet WCAG AA contrast compliance for both light and dark modes.

### CLI

Create projects, add primitives, and manage your Solidiom workspace from the command line. The CLI includes registry signing verification using Ed25519 keys with Sigstore-based provenance.

## Key Features

### Accessible by Design

- **axe-core** — Every primitive passes automated accessibility scanning
- **Keyboard navigation** — Full keyboard contracts per primitive, tested in real browsers
- **VoiceOver evidence** — Manual testing evidence captured for all primitives
- **ARIA semantics** — Compile-time enforcement via TypeScript generics

### Bilingual

All documentation and user-facing content available in English (en) and Spanish (es). Zero stale or missing translations verified at build time.

### CLI-Driven Workflow

- `solidiom create <project>` — Scaffold a new project
- `solidiom add <primitive>` — Add primitives to your workspace
- `solidiom registry verify` — Verify package integrity with Sigstore

### Registry with Integrity

- Ed25519 signing for all registry artifacts
- Sigstore-based provenance for supply chain security
- Integrity verification at install time

### Three Styling Recipes

CSS, Tailwind, and UnoCSS recipes tested against real primitives. One primitive, three styling outputs.

## Known Limitations

### Solid 2 Beta Dependency

Solidiom is built on Solid 2, which is itself in beta. API surface changes in Solid 2 may cascade to Solidiom primitives.

### Phase 4 Deferrals

The following are deferred to post-beta work:

- **Zoom** — Content zoom beyond 200% is not tested for all primitives
- **Contrast** — AAA contrast support; AA is the current target
- **Reduced motion** — `prefers-reduced-motion` adaptations are not yet comprehensive
- **Screen readers beyond VoiceOver** — NVDA, JAWS, and TalkBack testing is not yet complete
- **Touch** — Touch interaction patterns are not verified; focus is on keyboard and mouse

### API Stability

The public API may change between beta releases. No breaking changes are expected within the beta track, but migration guides will accompany any changes.

## Breaking Changes
