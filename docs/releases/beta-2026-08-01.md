# Public Beta — August 1, 2026

**Task:** BETA-003
**Status:** Published

Solidiom is now in public beta. The platform is functional and tested, but the API may change before a stable release. We welcome feedback and bug reports.

## What's Included

### Stable (M0–M2)

- **CLI** — Create projects, add primitives, and manage your Solidiom workspace from the command line.
- **Recipes** — Styling recipes for CSS, Tailwind, and UnoCSS, tested against real primitives.
- **Themes** — Installable theme presets with light/dark support and cross-tool parity.

### Beta (M3)

- **Primitives** — Headless, accessible building blocks. 3 primitives with full accessibility evidence; 49 more in preview.
- **Theme Builder** — Visual theme editor with import, export, and shareable links.

### Upcoming (M4)

- **Components** — Composed, opinionated components built on primitives.
- **Blocks** — Page-level composables: hero, footer, sidebar patterns.
- **Templates** — Full application templates with routing, state, and theming.

## Known Limitations

- The API is not yet stable and may change without a major version bump.
- Not all primitives have complete accessibility evidence; 3 are fully verified, 49 are in preview.
- Components, Blocks, and Templates are planned but not yet available.
- The registry is in development; installation currently uses workspace-based primitives.

## Feedback

We use GitHub Issues as our single feedback channel.

- **Bug reports:** Open an issue at https://github.com/openCenter-cloud/solidiom/issues
- **Feature requests:** Open an issue with the `enhancement` label
- **Security vulnerabilities:** Follow our responsible disclosure process — see https://github.com/openCenter-cloud/solidiom/security/advisories/new

**Do not report security vulnerabilities through public GitHub Issues.**

## Incident Contact

For issues affecting the site or infrastructure:

- Report via GitHub Issues for general problems.
- For security incidents, use GitHub's private vulnerability reporting.
- Response timeline: acknowledgment within 3 business days.

## Rollback

If a deployment causes issues, we can rollback instantly via Cloudflare Pages. See `docs/operations/rollback-procedure.md` for details.

## Deployment Notes

- Hosted on Cloudflare Pages with automatic HTTPS and global CDN.
- Preview deployments available for each pull request (team-only access).
- DNS: `solidiom.org` and `www.solidiom.org` both point to Cloudflare Pages.
