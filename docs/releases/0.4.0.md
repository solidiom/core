# Release 0.4.0

Beta release 0.4.0. This is a coordinated workspace-wide minor bump: every published `@solidiom/*` package moves from `0.3.0` to `0.4.0` in lockstep. The release advances the Solid 2 support window to `2.0.0-rc.1`, upgrades the TanStack table adapter to `@tanstack/table-core` v9, refreshes third-party dependencies across the CLI and adapters, and hardens the release tooling.

## Versioning

All 102 published packages are versioned together at `0.4.0`. The five internal-only packages (`@solidiom/bench`, `@solidiom/eslint-plugin-solidiom`, `@solidiom/adapter-kit`, `@solidiom/release-tools`, `@solidiom/test-doubles`) are excluded from release and remain unpublished.

## Highlights

- **Solid 2 support window advanced to `2.0.0-rc.1`.** Both `solid-js` and `@solidjs/web` are now pinned to `2.0.0-rc.1` (previously `2.0.0-rc.0`) in the root dev dependencies and workspace overrides.
- **TanStack table adapter rewritten against v9.** `@solidiom/adapter-table-tanstack` now targets the feature-modular `@tanstack/table-core@9` API. The public capability surface is unchanged.
- **CLI resolves caret ranges.** The CLI plans installs using caret ranges (e.g. `^0.4.0`) instead of exact pins, so consumers pick up in-range single-package releases without a registry regeneration.
- **Release pipeline hardened.** The Cloudflare token pre-flight now fails fast with setup guidance instead of failing silently.

## Notable package changes

Beyond the shared version bump, these packages carry behavioral or dependency changes in 0.4.0:

- **`@solidiom/adapter-table-tanstack`** — Upgrade `@tanstack/table-core` to v9. The adapter is rewritten against v9's feature-modular API (`tableFeatures` + `constructTable` with `createCoreRowModel` / `createSortedRowModel` / `createFilteredRowModel`), replacing the v8 `createTable` / `getCoreRowModel` shape. The public capability surface (`createTanStackTableAdapter` and the `TableModelCapability` interfaces) is unchanged, but consumers now resolve `@tanstack/table-core@9`.
- **`@solidiom/cli`** — Resolve registry package versions as caret ranges (e.g. `^0.4.0`) instead of exact pins when planning installs. Consumers now pick up in-range single-package releases without a registry regeneration. Pre-release versions and dist-tags are left unchanged. Also bumps `zod` to v4 (`z.record` now takes an explicit key schema) and `ts-morph` to v28, with no change to CLI behavior or output.
- **`@solidiom/adapter-virtualization-tanstack`** — Bump `@tanstack/virtual-core` to 3.17.8.
- **`@solidiom/adapter-date-internationalized`** — Bump `@internationalized/date` to `^3.12.3`.

### Dependencies

- Advanced the Solid 2 rolling window (`tools/solid-matrix.json`) to `{ low: 2.0.0-beta.34, mid: 2.0.0-rc.0, high: 2.0.0-rc.1 }` with peer range `^2.0.0-beta.34`.
- Bumped `solid-js` and `@solidjs/web` from `2.0.0-rc.0` to `2.0.0-rc.1` across the root workspace and templates.
- Refreshed all packages to their latest compatible releases (TypeScript kept on the 6.x line).

### Release tooling

- Fail-fast Cloudflare token pre-flight with setup guidance.
- Probe the Pages API in the Cloudflare pre-flight rather than `/tokens/verify`.
- Stop the Cloudflare pre-flight from failing silently.
- Added a script to unpublish versions.

### Site & branding

- Rebrand: quadrant mark applied across brand assets and site chrome.
- Point footer community links to on-site pages.
- Increase top-nav action spacing and add horizontal padding to the language switcher.

### Documentation

- Added an AI-assisted contributions policy.
- Synchronized documentation with the current implementation.
