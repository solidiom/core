# Solidiom GA Release Notes

**Task:** CUT-005
**Status:** Published
**Date:** August 7, 2026
**Version:** 0.0.1-ga

Solidiom GA marks the general availability of a complete, accessible, bilingual component platform built on Solid 2. This release publishes the full catalog, a signed V3 registry, a production CLI, cross-browser certification, and infrastructure behind a live site at solidiom.org.

## What's in GA

### Complete Catalog

- **52 primitives** — All stable. Headless, accessible building blocks with full accessibility evidence. Every primitive includes keyboard interaction contracts, ARIA semantics enforced at compile time, and committed axe-core scan results.
- **30 components** — Styled recipe wrappers for CSS, Tailwind, and UnoCSS. Compose primitives with layout, semantic styling slots, and variant support.
- **36 blocks** — Page-level composables across 12 categories: authentication, settings, billing, observability, enterprise workflows, data tables, forms, navigation, overlays, content, feedback, and layout. Each includes loading, empty, error, and restricted states.
- **29 templates** — Full application starters with routing, state, and theming. Balanced and Enterprise portfolios covering SaaS, internal tools, and commerce.
- **4 theme presets** — Ocean, Forest, Slate, and Aurora. All meet WCAG AA contrast compliance for light and dark modes.
- **3 styling profiles** — CSS, Tailwind, and UnoCSS outputs for the primitives supported by each recipe package.

### Accessibility

Solidiom GA ships with WCAG 2.2 AA compliance verified through three automated layers and manual evidence across seven dimensions:

1. **axe-core scans** — Automated accessibility scanning in real browsers. Zero violations across all primitives.
2. **Keyboard audit** — Complete keyboard interaction contracts tested with simulated key events for every primitive.
3. **VoiceOver verification** — Screen reader evidence captured and committed as artifacts for all primitives on macOS.
4. **7-dimension manual evidence** — Human-reviewed assessments covering: keyboard navigation, focus management, ARIA semantics, screen reader announcements, color contrast, cognitive load, and error handling.

ARIA semantics are enforced at compile time via TypeScript generics — missing attributes cause build errors, not runtime surprises.

### Bilingual

All documentation and user-facing content are available in English and Spanish. Translations are human-reviewed and verified at build time: zero stale, zero missing translations.

### Registry

The V3 registry index provides cryptographic integrity for all published packages:

- **Ed25519 signing** — Every package is signed with an Ed25519 key pair
- **Integrity hashes** — SHA-256 hashes for all package assets
- **Signed pointer** — A single signed index file points to all package manifests with cryptographic verification

### CLI

The `solidiom` CLI manages your workspace end-to-end with Sigstore-based verification:

| Command                    | Description                                          |
| -------------------------- | ---------------------------------------------------- |
| `solidiom plan <project>`  | Generate an installation plan                        |
| `solidiom add <primitive>` | Add a primitive to your workspace                    |
| `solidiom verify`          | Verify package integrity against registry signatures |
| `solidiom diff`            | Show changes between versions                        |
| `solidiom create <name>`   | Scaffold a new project                               |

Registry packages are verified with Sigstore-based provenance. The `solidiom verify` command checks all installed packages against V3 registry signatures.

### Cross-Browser

GA is certified on two rendering engines:

- **Chromium** — Chrome, Edge, and Chromium-based browsers fully supported
- **Firefox** — Gecko engine fully supported

WebKit (Safari 17.2+) has known limitations; see the [Limitations](../guides/limitations.md) document.

### Infrastructure

The Solidiom site runs on production-grade infrastructure:

- **Cloudflare Pages** — Global CDN with edge caching and automatic HTTPS
- **Security headers** — CSP, HSTS, X-Frame-Options, and other security headers configured and verified
- **Cache strategy** — Optimized cache headers for static assets, stale-while-revalidate for dynamic content

## Getting Started

### Installation

```bash
npx @solidiom/cli create my-app
cd my-app
pnpm install
pnpm run dev
```

### Your First Component

```bash
solidiom add accordion
```

The CLI adds the requested deliverable and any selected styling profile; recipe wrappers are available only for the supported primitive set.

### Migration from Scratch

Solidiom is a greenfield product — most users are starting from zero. See the [Migration Guide](../guides/migration.md) for workflows when starting from scratch, migrating from an existing Solid 2 project, or adopting from other UI libraries.

## Upgrade from Beta

```bash
npm update @solidiom/*
```

Review the changelog for any behavioral changes between Beta 1 and GA.
