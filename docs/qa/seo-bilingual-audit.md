## SEO Metadata

Every content page includes:

- `<title>` — unique, under 60 characters
- `<meta name="description">` — unique, under 160 characters
- `<link rel="canonical">` — self-referencing canonical URL
- `<link rel="alternate" hreflang="en">` — English alternate
- `<link rel="alternate" hreflang="es">` — Spanish alternate
- `<link rel="alternate" hreflang="x-default">` — default (English)
- `<meta name="robots">` — index,follow for public pages
- Open Graph tags (`og:title`, `og:description`, `og:type`, `og:url`)

## Structured Data

- **WebSite** schema on homepage with `SearchAction`
- **BreadcrumbList** schema on all content pages
- **SoftwareApplication** schema on primitive/component pages
- **Article** schema on guide pages (when published)

## Search (Pagefind)

- All content pages are indexed by Pagefind
- Search works in both locales with locale-filtered results
- Code blocks, theme tokens, and emails are excluded from search index (`data-pagefind-ignore`)
- Search UI is keyboard-accessible with `Ctrl+K` / `⌘+K` shortcut
